---
title: "Expander"
description: "A collapsible container with a header row and toggle glyph that reveals its content and reflows surrounding layout."
---

`Expander` shows a header row with a toggle glyph and reveals its content only when expanded. The collapsed control measures to just the header row, so surrounding layout reflows automatically.

## Properties

<ParamField path="Header" type="std::wstring" default='L""'>
  The caption rendered on the header row.
</ParamField>

<ParamField path="Expanded" type="bool" default="false">
  Expansion state. Toggling triggers a full measure pass so the layout reflows.
</ParamField>

<ParamField path="Content" type="unique_ptr<ControlBase>" default="nullptr">
  The single child revealed when expanded. Like `Border::Content`, reassigning it detaches the old child cleanly.
</ParamField>

<ParamField path="CollapsedGlyph / ExpandedGlyph" type="wchar_t" default="'+' / '-'">
  The glyphs drawn on the header row for each state.
</ParamField>

## Events

<ParamField path="ExpandedChanged" type="Event<bool>">
  Fired with the new state after every toggle.
</ParamField>

## Example

```cpp
auto details = init<Expander>([](Expander* e)
{
    e->Header = L"Advanced options";

    e->Content = init<StackPanel>([](StackPanel* p)
    {
        p->AddChild(init<CheckBox>([](CheckBox* cb) { cb->Text = L"Verbose logging"; }));
        p->AddChild(init<CheckBox>([](CheckBox* cb) { cb->Text = L"Debug mode"; }));
    });

    e->ExpandedChanged += [](bool expanded) { /* persist the state */ };
});
```

Keyboard: Enter or Space toggles the expansion when the header is focused. `Expand()`, `Collapse()`, and `Toggle()` do it programmatically.
